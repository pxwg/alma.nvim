*alma.nvim* Native Neovim frontend for Alma

Requirements~

Neovim 0.12.0 or newer is required. The local Alma API defaults to:

  http://127.0.0.1:23001

Set `ALMA_API_URL` or pass `api_url` to setup to override it.

Setup~

>lua
  require("alma").setup({
    api_url = vim.env.ALMA_API_URL or "http://127.0.0.1:23001",
  })
<

Commands~

                                                        *:AlmaHealth*
`:AlmaHealth` checks Neovim, curl, and Alma API availability.

                                                        *:AlmaThreadOpen*
`:AlmaThreadOpen {thread_id}` opens a Neovim buffer for one Alma thread.

                                                        *:AlmaSubmit*
`:AlmaSubmit [prompt]` sends a prompt through `/ws/threads`. Without arguments,
it reads the editable bottom `## You` composer in the current Alma buffer.

                                                        *:AlmaStop*
`:AlmaStop` sends a `stop_generation` WebSocket request for the current thread.

                                                        *:AlmaThreads*
`:AlmaThreads` opens the snacks picker thread list.

                                                        *:AlmaModels*
`:AlmaModels` opens model and reasoning selection.

                                                        *:AlmaTools*
`:AlmaTools` toggles tool defaults for the current thread.

                                                        *:AlmaSkills*
`:AlmaSkills` toggles skill defaults for the current thread.

                                                        *:AlmaMCPServers*
`:AlmaMCPServers` toggles MCP server defaults for the current thread.

                                                        *:AlmaEvents*
`:AlmaEvents` opens the raw WebSocket/debug event picker.

                                                        *:AlmaToolDetails*
`:AlmaToolDetails` opens a scratch detail buffer for the block under cursor.

                                                        *:AlmaQuickfix*
`:AlmaQuickfix` extracts file locations from the current thread into quickfix.

                                                        *:AlmaDiff*
`:AlmaDiff` opens patch-like block output in a diff scratch buffer.

Completion~

Use this blink.cmp provider:

>lua
  require("blink.cmp").setup({
    sources = {
      default = { "lsp", "path", "snippets", "buffer", "alma" },
      providers = {
        alma = {
          name = "Alma",
          module = "alma.completion.blink",
        },
      },
    },
  })
<

Token-only prompt lines configure the request:

  /skill:<id>
  @Bash
  @mcp:<server>
  $model:<id>
  $reasoning:low|medium|high|xhigh
  >buffer
  >selection
  >diagnostics
  >diff
  >file:<path>
  >zk:<id>

Reliability~

alma.nvim turns the bottom `## You` composer into the sent user message,
renders one loading Alma response, and locks the buffer while generation is in
flight. If the same thread is already generating, the request is queued in
Neovim and visibly marked as queued. Generation completion or failure always
reconciles through REST messages.
